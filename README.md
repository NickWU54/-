# 九方社区 PC 玩法配置与页面搭建原型

可交互的 PC 端运营原型，使用示例数据。

- **玩法搭建后台**：玩法选择 → 基础信息 → 任务行为 → 发奖领奖配置，包含阶梯玩法与抽奖玩法。
- **运营页面组装**：左侧组件库、中间 H5 画布、右侧属性配置，支持阶梯、抽奖、任务列表等组件。

## 使用

直接打开 `index.html`，或通过 GitHub Pages 访问。建议使用桌面浏览器。

所有样式与脚本均打包在 `index.html` 中，无需安装依赖或构建。配置草稿保存在当前浏览器本地；原型不连接真实社区账户、不执行实际发奖。

## GitHub Pages

在仓库 Settings → Pages 中，选择 Deploy from a branch，使用 `main` 分支的 `/(root)` 目录。

## 更新

替换 `index.html` 并提交到 `main` 分支，GitHub Pages 会重新发布。
